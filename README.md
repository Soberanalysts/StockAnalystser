# StockAnalystser

국장·미장·일장 관심종목을 섹터별로 표준화해 커플링(미장 → 국장 선행 신호)을 보기 위한 자료.

## 관심종목/
- `원본/` : 영웅문·영웅문 Global에서 내보낸 원본 CSV (국장, 미장, 일장)
- `정리안/` : 표준 탭 체계로 재정리한 CSV. 영웅문에서 그대로 불러오기용
  - `안전판/` : 새로 추가한 종목 줄을 뺀 버전 (불러오기 오류 시 사용)
  - `테스트/` : 불러오기 오류 원인 확인용 시험 파일
- `*_구간표준.xlsx` : 탭별 국장·미장·일장 구간 비교표

## 주의
- CSV는 CP949 인코딩, CRLF 줄바꿈입니다. 엑셀이나 편집기로 열어 저장하면 형식이 바뀌어 영웅문 불러오기가 실패할 수 있습니다.
- `.gitattributes`의 `*.csv -text` 설정으로 Windows/Mac 사이 줄바꿈 자동 변환을 막아 둡니다.
- 빈칸메모(구간 이름)는 불러오기로 반영되지 않아 영웅문에서 직접 입력해야 합니다.
